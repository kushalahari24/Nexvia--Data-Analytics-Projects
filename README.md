Nexvia Technologies – Data Analytics Projects

This repository contains two Data Analytics projects completed as part of the Nexvia Technologies Data Analytics Internship.

DA-01: Enterprise Business Intelligence Suite

Objective: Build an integrated Business Intelligence solution for a multi-region company.

Tools & Technologies:

- SQL Server Express
- Power BI Desktop
- Power Query
- DAX
- SQL

Key Deliverables:

- Sales Dashboard
- Finance Dashboard
- Product Dashboard
- Customer Dashboard
- HR Dashboard
- Supply Chain Dashboard
- KPI cards, slicers, charts and drill-through reports
- Row-Level Security (RLS)
- SQL data export and refresh automation
- Project documentation, testing report, presentation and user guide

DA-02: Customer 360 and Marketing Attribution Platform

Objective: Develop a unified customer analytics solution and analyze marketing channel performance.

Tools & Technologies:

- Google BigQuery
- SQL
- Power BI

Key Deliverables:

- Customer 360 data analysis
- Customer RFM and CLV analysis
- First-touch and last-touch attribution
- Linear and time-decay attribution
- Channel attribution comparison
- Customer analytics and marketing insights
- SQL scripts, dashboard, documentation, testing report and demo recordings

Note: The DA-02 SQL folder contains recovered and organized SQL scripts from the project analysis. It does not represent every original query executed in BigQuery.

Repository Structure

- "DA-01/" – Enterprise Business Intelligence project
- "DA-02/SQL/" – Customer 360 and Marketing Attribution SQL scripts
- "README.md" – Overview of both projects
